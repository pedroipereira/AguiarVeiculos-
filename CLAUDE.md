# Aguiar Veículos — Contexto do Projeto

Revenda de veículos (novos e seminovos) em Presidente Dutra - MA, no mercado há 15+ anos. Ver `contexto/empresa.md` para visão geral do negócio.

## Regras de trabalho
- Antes de qualquer tarefa **visual** (carrossel, post, site, peça gráfica): ler `identidade/marca.md` primeiro.
- Antes de escrever **qualquer texto** da marca (legenda, anúncio, mensagem): ler `marketing/voz-e-tom.md` primeiro.
- Todo entregável final vai para a pasta `output/`.
- Idioma padrão dos entregáveis: português (salvo pedido diferente).
- `_fontes/` é matéria-prima bruta (export do Instagram) — não ler no dia a dia, só para reprocessar/enriquecer o contexto quando pedido.
- Estes arquivos de contexto são vivos: se um dado mudar (preço, produto, campanha), atualize o arquivo correspondente.

## Pendências (marcadas como [A DEFINIR] nos arquivos)
- `marketing/voz-e-tom.md`: palavras/expressões proibidas
- `contexto/dados.md`: preços, ticket médio, volume de vendas
