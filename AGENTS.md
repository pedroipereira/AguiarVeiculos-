# Instruções para trabalhar no site

- Comece pelo README.md e CONTRIBUTING.md.
- A aplicação fica em site/. Preserve esse caminho e a configuração de publicação.
- Use uma branch de trabalho baseada na main atual; preserve alterações existentes.
- Não copie contexto comercial, pesquisa, fotos originais, matrizes de marca ou credenciais do workspace interno para este repositório público.
- As referências históricas a contexto/, marketing/ e identidade/ em comentários remetem a materiais do workspace interno; não são dependências de execução.
- Não reescreva o histórico nem use push --force para organizar arquivos.
- Valide alterações de código com os testes e build descritos em CONTRIBUTING.md. Para documentação, confira caminhos, links e escopo do diff.
- main está ligada à produção. Considere esse efeito antes de integrar mudanças.
